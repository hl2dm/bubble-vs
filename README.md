# 泡泡龍對戰 bubble-vs

網頁版雙人對戰泡泡龍（Puzzle Bobble 風格），沈柏楊（綠營）vs 蔣萬安（藍營）。

**線上直接玩：** https://hl2dm.github.io/bubble-vs/

## 玩法
- 發射泡泡，湊滿 3 顆以上同色即可消除，失去連結的泡泡會掉落。
- 泡泡碰到左右牆會反彈；天花板會定時下降一格。
- 一次打落 3 顆以上泡泡，會送垃圾泡泡給對手。
- 任何泡泡越過紅色虛線就輸了。三戰兩勝制。
- 技能條集滿後可發動技能，在對手版面頂端塞入兩排自己陣營顏色的泡泡。

## 操作
| | 瞄準 | 發射 | 技能 |
|---|---|---|---|
| 單人 | ← → 或 A / D、滑鼠 | 空白鍵 / ↑、滑鼠點擊 | Shift / E |
| 雙人・左方 | A / D | W | E |
| 雙人・右方 | ← → | ↑ | Enter |

其他：Esc 暫停／返回、M 靜音、F 全螢幕。

## 本機執行
直接用瀏覽器開啟 `index.html`，或在資料夾內執行 `python -m http.server` 後開啟 http://localhost:8000 。
